| Folder | Contents | Manuscript role |

| `results/main_phikon_8seed/` | Eight-seed ABMIL/TransMIL baseline-versus-CED results and summaries using Phikon features | Main cross-backbone robustness analysis and paired statistics |

| `results/statistics/` | Bootstrap confidence intervals and paired permutation-test summaries | Statistical significance analysis |

The repository intentionally excludes exploratory and superseded artifacts that are not required to interpret the reported analyses.
